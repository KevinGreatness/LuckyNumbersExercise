The problems:
1) How to calculate Lucky number by birthday: take a birthday string such as 05-15-1979, add all the numbers together.
   If the sum is a single digit, that is the lucky number. If not, repeat the process by summing the digits of the
   new number. 05-15-1979 would first be 0+5+1+5+1+9+7+9=30. Repeating the process gives 3+0=3. Lucky number = 3.
2) How to calculate Lucky number by name: assign each letter in the alphabet a value, from 1-26 for a-z. Calculate the
   sum of the initial name. Then repeat the process from #1 and figure out the single digit number.
